使用说明
终端使用 1. 点击左侧 实验按钮 展开需求列表
2. 点击 需求项，命令或脚本自动填入
3. 按 Enter 键执行命令
4. 也可直接在终端输入框中 输入命令
5. 输入 sudo 命令需验证密码（默认密码为当前用户名）
6. 按 Ctrl+Shift+P 自动填充 sudo 密码
7. 终端输出文本可 直接点击修改
8. 在终端弹窗内点击 用户设置 / 组设置 打开图形化管理（实验一相关）
9. 点击标记为 脚本实验 的主按钮 打开脚本编辑器
10. 在脚本编辑器中 保存 脚本后，可在终端执行
自定义题目（新增） 11. 点击左侧底部 ⚙ 自定义题目 打开管理面板
12. 新建 / 重命名 / 删除 实验，调整实验下题目的顺序
13. 每条题目支持设置：显示名 · 终端命令 · 脚本内容 · 文件名
14. 命令和脚本可并存（有脚本时点击会打开脚本编辑器）
15. 顶栏 📤 导出 JSON 可备份本届题目，📥 导入 JSON 可恢复
16. 改动自动保存到浏览器，刷新不丢；可随时 🔄 恢复默认
虚拟机快照 17. 终端里的文件、用户、组改动会自动保存，刷新后继续上次的环境
18. 需要全新环境时点击
19. 支持 | 管道、> / >> 重定向、&& 与 ; 命令链，以及 grep/head/tail/wc/sort 等命令
服务器同步 20. 题库保存在服务器数据库中，所有人共用一份：任何人修改保存后，大家下次打开都能看到
