# Ubuntu Terminal - 操作系统实验报告生成器

一个基于 Web 的 Ubuntu 终端模拟器，用于快速生成操作系统实验报告。

## 功能特性

### 终端模拟
- 完整的 Linux 命令行交互体验
- 支持常用命令：`ls`、`cd`、`cat`、`mkdir`、`rm`、`cp`、`mv`、`chmod`、`chown`、`find`、`touch` 等
- 文本处理：`grep`、`head`、`tail`、`wc`、`sort`、`echo`、`date`、`history`、`man`、`true`/`false`
- 用户/组管理：`useradd`、`userdel`、`usermod`、`groupadd`、`groupdel`、`gpasswd`、`passwd`、`su`、`sudo`
- 磁盘管理：`fdisk`（交互式子命令）、`mkfs`、`mount`、`umount`、`df`、`du`
- 链接与属主：`ln`（软/硬链接）、`chown`、`chgrp`
- 管道 `|`、重定向 `>` / `>>`、命令链 `&&` / `||` / `;`（按上一命令退出码决定是否继续）
- 文件参数通配符展开：`ls *.sh`、`chmod +x *.sh` 等（`find -name` 的参数不展开）
- 环境变量展开：`echo $USER`、`$HOME`、`$PWD`、`$SHELL`、`$HOSTNAME`
- 命令历史：`history` 查看、方向键 ↑/↓ 翻阅，跨刷新保留

### 权限与安全模型
- 完整的 rwx 权限检查：读（`cat`/`grep`/`head` 等）、写（`rm`/重定向）、执行（`./script.sh` 需先 `chmod +x`）
- `sudo` 密码认证（默认密码为用户名）：管道内的 sudo 同样触发认证；认证后特权仅对带 sudo 前缀的命令生效，与真实 Ubuntu 一致
- 密码连续输错两次后提示默认密码，也可按 Ctrl+Shift+P 自动填充
- 用户名/组名创建时过滤特殊字符，全部用户输入输出经 HTML 转义，并带 CSP 兜底

### 虚拟文件系统
- 完整的目录树结构（`/home`、`/etc`、`/var`、`/usr` 等）
- 文件权限系统（`rwx` / 八进制），符号链接支持
- 磁盘分区与挂载模拟，`fdisk` 分区改动持久保存
- 日志时间戳（`/var/log/syslog` 等）跟随真实系统时间动态生成

### Shell 脚本模拟
- 支持 `if/elif/else`、`while`、`for` 循环
- 变量赋值、`let` 算术运算、`$((...))` 表达式、命令替换 `$(...)`
- 函数定义与调用，`test` / `[ ]` 条件测试
- `read` 弹出输入框请求真实输入（预置答案仅作默认值）

### 虚拟机快照（持久化）
- 终端里的文件、用户、组、磁盘分区、命令历史自动保存到浏览器
- 刷新后输入同名用户名即可恢复上次环境
- 帮助面板提供"重置虚拟机"一键恢复初始状态

### 实验报告生成
- 预置多个操作系统实验题目（用户与组管理、文件与磁盘管理、Shell 脚本编程）
- 一键填入命令或脚本，脚本编辑器可视化编写保存
- 支持自定义实验和题目管理，数据导出/导入（JSON 格式）
- **共享题库（可选）**：题库存一份在服务器 MySQL 数据库中，所有人共用——任何人修改保存后，其他人下次打开页面即可看到；localStorage 作为离线缓存，断网或未部署 PHP 时回退代码内置版本
- **自动备份与恢复**：题库每次被修改，修改前的版本自动备份为服务器上的 JSON 文件（保留 3 个月，最近 10 份保底永不清理）；备份目录禁止列览、文件名不可猜测、HTTP 层无删除接口（仅超期自动清理）；自定义面板"🕘 备份与恢复"可随时回滚，恢复操作本身也会留档，可再撤销。另设 `origin.json` 初始版本**永久留档**（只读，永不覆盖/永不过期/清理不涉及），题库无论被改多少次都能一键回到原版
- 题目数据模型为内联 items（每道题完整存在所属实验里），自定义/新增题目完整持久化，不再依赖全局下标引用

## 部署

纯静态页面 + 可选 PHP 后端：

1. 静态部分：任意静态托管即可，入口 `index.html`
2. 共享题库（需要 PHP + MySQL）：
   - 将 `api/` 目录部署到站点
   - 复制 `api/db.example.php` 为 `api/db.php`，填入数据库凭据（`db.php` 已被 `.gitignore` 排除，不会提交）
   - 首次访问会自动创建 `os_experiments` 表；题库首次需通过页面保存一次（或手动向 `#default#` 行写入）来初始化
   - 无 PHP 环境时页面仍可正常使用，题目数据退回 localStorage 保存

## 使用方法

1. 直接在浏览器中打开 `操作系统实验.html`（或部署到任意静态托管，入口为 `index.html`）
2. 输入用户名开始使用（该用户名同时作为默认 sudo 密码）
3. 点击左侧实验面板选择题目，命令自动填入终端，按 Enter 执行
4. 脚本类题目点击后打开脚本编辑器，保存后用 `bash 文件名` 或 `chmod +x` 后直接运行

## 文件说明

| 文件 | 说明 |
|------|------|
| `操作系统实验.html` | 主页面 |
| `app.js` | 核心逻辑（终端模拟、文件系统、命令处理、脚本解释器） |
| `styles.css` | 样式文件（含窄屏响应式布局） |
| `tests.html` | 单元测试页（浏览器打开即自动运行，48 项断言） |
| `api/experiments.php` | 自定义题目存取 API（PHP + MySQL，可选） |
| `tests.js` | 单元测试（路径解析、权限、通配符、管道、grep/sort 核心等） |

## 开发

- 纯前端实现，无需后端服务
- 原生 JavaScript，无框架依赖
- 数据持久化使用 localStorage
- 运行单元测试：浏览器打开 `tests.html`，全部通过会显示"全部通过：48 项"
